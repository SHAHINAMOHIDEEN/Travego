# Travego – Transport Management System

# Project Overview
Travego is a MySQL-based database project designed to manage passenger information and transportation records efficiently.

# Objectives
- Organize passenger and transport-related data.
- Retrieve information using SQL queries.
- Apply relational database concepts for data management.

# Tools Used
- MySQL
- MySQL Workbench
  
# Key SQL Concepts
- SELECT, WHERE, and ORDER BY
- JOIN operations
- Aggregate functions
- Relational database management

# Project File
- "Travego_Project.sql" – Contains the SQL queries used in the project.

# Conclusion
This project demonstrates practical SQL skills in database management, data retrieval, and analysis.
